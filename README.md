# RobinWheelAndTweaks

Made by RobinTheSoundsmith. This Dusklight code mod adds a second item wheel with 24 mod-owned item slots, Shield Surf, a Sit action, and a separate Goron Tunic slot. It reuses the vanilla item-wheel presentation while handling slot identity, selection, movement, and rendering independently of vanilla inventory indexes. Hawk Grass is provided in the first secondary slot and Hover Boots in the second; both can be assigned to X or Y.

## Repository contents

- `src/mod.cpp` contains the mod implementation.
- `mod.json` contains the Dusklight mod manifest.
- `CMakeLists.txt` defines the mod target for Dusklight's CMake build.
- `res/` is the mod's resource directory. The wheel loads its presentation from Dusklight at runtime and includes custom winged Hover Boots, Dark Link, Ice Arrow, and text-based Sit icons.

## Building

This mod is built from a Dusklight source checkout, which provides the SDK, headers, libraries, and `add_mod` CMake function. Place this directory at `mods/secondary_inventory_wheel` and ensure the checkout's top-level `CMakeLists.txt` includes:

```cmake
add_subdirectory(mods/secondary_inventory_wheel)
```

Configure Dusklight as usual, then build the `secondary_inventory_wheel_package` target. The build produces `secondary_inventory_wheel.dusk`.

## Slot model

Dark Link Form uses the game's Link-warp appearance/disappearance particles and a 30-frame head-to-feet shader sweep. Each body/outfit material turns pitch black as the irregular, blocky edge passes it; deactivation reverses the sweep from feet to head. Materials or bound textures named specifically for pupils, irises, or hitomi receive the fullbright red shader. At full transformation, a final TEV override is applied immediately before each queued Link shape draws, so cached material and shape display lists cannot restore the face, sword, or sheath colors. It identifies each shape from its owning model packet because the game renders queued shapes after Link's per-model draw callback has returned. In combat, Link's sword attacks deal four times normal damage, and incoming damage is multiplied by four relative to the game's normal damage calculation.

The secondary wheel has 24 mod-owned item slots (`0x80` through `0x97`), followed by dedicated **Shield Surf** (`0xFC`), **Sit** (`0xFD`), and Goron Tunic (`0xFE`) slots. Its opening and closing pose and fade use Dusklight's frame interpolation, and stick navigation advances one slot per the vanilla cursor-change wait. Custom item IDs and the dedicated slot IDs are private to the mod and are never written into the game's vanilla X/Y item assignments. The two secondary assignments are saved independently in the mod configuration. Assigning a secondary item to X or Y leaves that button's vanilla assignment intact; while a secondary item is assigned, it takes precedence for that button's HUD icon and activation. Assigning a vanilla item to that same button from the vanilla wheel clears its private secondary assignment so the vanilla item immediately takes over. Shield Surf uses Link's currently equipped shield as the board and reuses the native Ice Leaf board movement on any walkable ground; the pointed top of the shield faces forward. Assign it to X or Y, press the button to start, and press it again to dismount. Its temporary board actor is kept in the native ride-only mode so it cannot order the Ice Leaf pickup event, including on collisions, and is deleted as ride state is cleared. Starting a get-item event or cutscene ends Shield Surf and clears its ride state so Link can move normally afterward. It does not replace the vanilla Ice Leaf item or alter normal Ice Leaf behavior. Hawk Grass uses its private item ID in the first slot and displays a custom Hawk Grass icon. Its assigned X/Y action enters the game's grass-whistle flow, retaining the native reed melody and hawk sound effects. After its attack and return flight finish, the Hawk called by modded Hawk Grass is removed after five seconds in idle with Link outside the Hawk interaction. Hover Boots use their private item ID in the second slot and a custom boots-with-wings icon in the wheel, X/Y preview, and HUD. The X/Y HUD icon is rendered directly from the mod resource, without using a vanilla item ID to load or scale it. Assign them to X or Y and press that button to toggle airwalking immediately; the Iron Boots equip animation plays on ground and in the air but does not gate the Hover Boots state change or modify vanilla Iron Boots. While active, the magnetic-boots particles follow Link’s foot joints immediately, including while he is still standing on solid ground. When Link walks or jumps off solid ground, Hover Boots keep him at the height where he left it and show a ripple beneath him. While airborne, the mod prevents vanilla auto-fall/ledge actions from replacing the current player action, including idle movement states, while allowing other mods' jump actions to run. At the hover plane it uses a one-shot landing animation and returns Link to movement without requiring a background polygon. The Sit slot displays a text-based **SIT** icon and uses Link's gameplay `WAIT_SIT` animation. While seated, it keeps Link at the current floor height, tilts his body to walkable floor slopes, lowers the model 28 units toward the surface, and offsets the rendered model 65 units forward in Link's facing direction without moving ground collision. The leg pose itself remains the one authored in `WAIT_SIT`; straightening it would require a custom animation. Press the assigned X/Y button again to restore the normal standing idle. Movement input is suppressed while seated. The mod does not add an A-button jump. The normal A-button put-away behavior for vanilla held items is unchanged. The new Dark Link Form is provided in the third secondary slot with its own shadow-warrior icon in the wheel, X/Y preview, and HUD. Press its assigned button to activate and press it again to return to normal; assigning it does not activate the form. The form preserves Link's regular movement and animation and leaves Wolf Link unchanged. Ice Arrow appears directly after Dark Link Form in the wheel with its custom blue arrowhead icon; it is an informational bow feature, not an item to assign to X or Y. With a bow equipped, hovering over Ice Arrow shows the game's native R-button combo prompt and flashing combo indicator. Press R to toggle Ice Arrow mode on or off; the selected arrow is spawned with Ice Arrow's type while the mode is on. After updating from older versions, assign secondary items again in the secondary wheel; the old implementation mirrored those assignments into vanilla item state.

The mod settings remain available in the Mods panel and can also be opened directly from the menu bar's **Robin's W&T** entry. The menu lets players choose which Left/Down D-pad direction opens the secondary wheel, walk on lava indefinitely with the Goron Tunic (without sinking or triggering the five-second lava return), toggle Twilight Ward, enable one-hit damage for attacks from the Hawk called by the secondary Hawk Grass, toggle Hover Boots water walking, and select music to play while sitting. **File Select** is currently the only Sit music option; it uses the game's native File Select BGM sequence. When Link sits, the current area soundtrack fades out before File Select starts through the main BGM route, replacing the area sequence. The current scene's wave archives are preserved, and the original archive state and main sequence are restored when Link stands or Sit ends. The selected sequence bypasses the fanfare queue, and battle-managed BGM is held off for the duration so it cannot interrupt the track. Infinite lava walking overrides the heavy-armor sinking surface state while Link is on lava. Vanilla recalculates that state during room setup, so the mod corrects it after that calculation; when lava walking is disabled, lava under heavy armor is also kept out of the quicksand-return path that expects a sand-only transform buffer, allowing the game's magma-return logic to handle it. The Goron Tunic visual override uses the game's armor-specific material slots for Zora Armor, Magic Armor, and Ordon Clothes, and reapplies the tint at draw time after material animation and lighting updates. Twilight Ward is off by default and, while Link wears Magic Armor, normal and heavy hits still deal their usual damage but do not interrupt Link, stun him, or knock him back. Water walking is off by default and only applies while the secondary-wheel Hover Boots are equipped; it keeps movement on a flat water-level plane instead of using submerged floor slopes, drops, or ice-slip movement. It also suppresses submerged slide-polygon and slope checks and clears the vanilla ground-step offsets while the water plane is active. Enabling water walking replaces airwalking, so players can choose which Hover Boots behavior they prefer. With the one-hit option enabled, player targets take 20 hearts of damage. The modded Hawk's attack is classified as a thrown object, normal sword hit, and bomb for compatibility with enemy-specific damage handlers, including mounted Bulblins.

The menu also provides Rupee Magnet as an optional feature rather than a wheel item. Its radius defaults to 100% (300 game units, matching the game's existing rupee-return distance) and can be set from 50% (150 units) to 300% (900 units) in 25% steps. Lava walking, Twilight Ward, Hawk one-hit damage, Hover Boots water walking, and Rupee Magnet are off by default.

The **Shield Surf R-button speed boost** is an optional menu setting, off by default. While Shield Surfing, hold the game's R button to gradually accelerate from the current speed to the vanilla Ice Leaf maximum of 70 game units per frame, then maintain that speed while R remains held. The boost uses the native 4-unit push acceleration; releasing R restores vanilla speed behavior.

When Goron Tunic lava walking is disabled, Link keeps the gradual lava sink and a five-second magma-return delay. The delay restarts if Link leaves the lava, so separate contacts do not accumulate time.

The secondary wheel's close behavior matches the vanilla wheel, including restoring background music and sound-effect levels when the wheel closes.

## Ice Arrow

While aiming with Ice Arrow mode enabled, the mod renders an Ice Keese model at the tip of the held arrow, like the bomb model on a bomb arrow. It disappears when the arrow is fired and is not a HUD indicator.

With a bow equipped, hover over the Ice Arrow wheel entry and press R to bind Ice Arrow mode; press R again there to unbind it. The secondary wheel shows the native bow-and-arrow combo prompt only while Ice Arrow is unbound, and shows the combo-off prompt only while it is bound. While bound, pressing R with the bow drawn returns to ordinary arrows; while unbound, the standard bow does not show a switch prompt. Ice Arrow is a temporary bow mode, not an inventory item, and cannot be assigned to X or Y. A hit applies the game's freeze tint and holds the enemy's main model pose and position for up to 90 frames (three seconds), suppressing its attack collider while retaining its target collider so it can still be damaged. The tint is restored when the freeze ends, and killing an enemy immediately releases it so its death and despawn can proceed. Common enemies and bosses are eligible; NPCs, props, shielded hits, and arrow-through targets are excluded. Actors with separately managed secondary models may not freeze every mesh, and projectiles already in flight are unaffected.

## Sit While Hovering

With airwalking Hover Boots equipped, Sit can be started from the stable hover plane as well as from the ground. Link stays suspended at that height while seated; standing returns him to movement without dropping him.

## Goron Tunic Armor Changes

The Goron Tunic tint pauses while the game's armor-change animation is replacing Link's clothing models, then resumes once the new models are ready.
